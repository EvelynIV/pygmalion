# 侧边栏同步交接

Figma 文件：<https://www.figma.com/design/m1toyRcCag4OOsJNMebFDb>

已将 121 处桌面及状态稿侧边栏同步为共享组件 `Console/Sidebar`，包含投稿管理、书写队列、机器控制、纸张校准、参数设置五种选中状态，并支持白昼、夜间主题。

- 侧栏宽 208px，品牌区域高 80px，菜单高 36px、间距 2px、图标 16px。
- 侧栏横向内边距 14px，底部复制操作高 32px；返回入口统一为“返回投稿”。
- 右侧工作区随侧栏宽度重排；主页面与原型跳转目标保持稳定。
- 无登录页、鉴权接口或退出登录操作。
- 设计中的投稿数量、网络地址和任务进度用于展示；代码使用接口返回值。
